# ASD-STE100 limits

Source of these numbers: the overview sheet attached to Karpathy's post (2 Oct 2026), which summarizes ASD-STE100 (Simplified Technical English, asd-ste100.org). The full specification is larger (~900 approved words). Use these limits. Do not invent extra dictionary rows.

Karpathy's own softening: ask for about 80% of the way to ASD-STE100. Apply the limits below. Skip only a rule that would hide a technical name the source needs.

## Sentence and paragraph limits

| Unit | Max |
|---|---|
| Procedural sentence | 20 words |
| Descriptive sentence | 25 words |
| Sentences in one paragraph | 6 |
| Words in a noun cluster | 3 |
| Instructions in one sentence | 1 (except two actions that happen together) |

Also:

- One topic per paragraph.
- Keep articles: the, a, this. Do not drop them.
- Active voice in procedures. Name the actor.
- Same word for the same thing. No synonyms.
- Vertical list when the text is a sequence of steps.
- Safety: first the command, then the risk. WARNING = injury. CAUTION = damage.

## Verb forms

| Form | Example | Status |
|---|---|---|
| Command (imperative) | Close the valve. | Approved |
| Simple present | The valve closes. | Approved |
| Simple past | The valve closed. | Approved |
| Simple future | The valve will close. | Approved |
| Infinitive | Turn the knob to close it. | Approved |
| Past participle as adjective | The closed valve. | Approved |
| Progressive (-ing) | The valve is closing. | Not approved |
| Perfect | The valve has closed. | Not approved |
| Passive in a procedure | The valve must be closed. | Not approved |

Use -ing only inside a technical name (landing gear). Passive only in descriptive text, and only if the actor is unknown.

## Dictionary swaps

Approved words keep one part of speech and one meaning. CLOSE is a verb. It is not the adjective "near".

| Do not write | Write |
|---|---|
| close (adjective) | NEAR |
| commence | START |
| ensure | MAKE SURE |
| prior to | BEFORE |
| replenish | FILL |
| utilize | USE |
| approximately | ABOUT |
| in order to | TO |

Pattern, not a full dictionary: if a verb has a plain approved equivalent (use, start, stop, fill, test, make sure), use that equivalent. TEST means "find if it operates correctly".

## 80% mode

Keep: word caps, one instruction, active voice, no synonym swap, the table above.
Relax only: a technical name longer than 3 words, if splitting it would change the referent. Mark that name on first use.
